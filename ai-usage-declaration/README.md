# AI Usage Declaration (khai báo sử dụng AI)

Thư mục chung để **mỗi người tự điền phần của mình**. Cuối cùng gộp thành một file Markdown (và PDF) để nộp theo yêu cầu của thầy.

## Cách làm
1. Mở file của bạn (`01_...` đến `05_...`) và **điền hết các ô trống**, bằng lời của chính bạn.
2. Làm trên **nhánh riêng và PR riêng**, commit bằng tài khoản của bạn. Không sửa file của người khác.
3. File `00_Chung.md` là phần chung của nhóm; Bảo An tổng hợp, cả nhóm đọc và xác nhận.

## Nguyên tắc
- **Khai báo trung thực.** Đề cho phép dùng AI, nhưng phải review và nhận trách nhiệm. Ghi đúng việc AI làm, không ghi thiếu hay ghi quá.
- Chỉ ghi là "đã review / đã chạy lại" nếu **bạn thực sự đã làm**.
- **Không dán API key, mật khẩu, thông tin cá nhân.** Có thể tóm tắt prompt, không cần dán toàn bộ cuộc trò chuyện.
- Nếu chưa chắc phần nào do AI viết, ghi "không chắc" thay vì đoán.
