# Ảnh minh chứng Tuần thực hành 04

Trang xem minh chứng: [MinhChung_Tuan_04.html](../../bao-cao-tuan/MinhChung_Tuan_04.html).

- `screenshots/`: 5 ảnh PNG từ trình duyệt.
- `screenshots.json`: thời điểm chụp UTC.
- `results.json`: 5 request/response HTTP thật.
- `run.json`: thông tin khởi chạy ứng dụng và trang kiểm tra API.
- `package.log`: đóng gói offline có skipTests; không coi đây là một lượt chạy test.
- `application.log`: log ứng dụng Java 25 trong lúc chụp.

Trang kiểm tra API phục vụ minh chứng, không phải UI của sản phẩm. Không quay hoặc đính kèm video theo yêu cầu nhóm.
